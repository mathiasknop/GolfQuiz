# Golf Quiz — User Manual

> A real-time quiz app for The National Golf Brussels.
> Players answer on their phones, the host scores on a tablet or laptop.

---

## Getting Started

Open the app in any browser. You'll see the **Lobby** with three options:

| Action | Who it's for |
|--------|-------------|
| **New Quiz Session** | Host starting a fresh quiz night |
| **Join Existing Session** | Host resuming a previous session |
| **Join as a Player** | Team members answering on their phone |

At the bottom of the lobby you'll also find links to **View All Sessions** and **Manage Quiz**.

---

## For the Host

### 1. Create a Session

Tap **New Quiz Session**. The app generates a unique session code (e.g. `GQ-K7MP`). Share this code with all players.

### 2. Set Up Teams

On the **Setup** screen:

- Use the **slider** to set the number of teams (2–20).
- Edit each **team name** in the list (defaults to "Team 1", "Team 2", …).
- Tap **Start Scoring** when ready.

All changes are saved automatically.

### 3. Print Answer Sheets

From the **Setup** screen, tap **Answer Sheets** to generate printable A4 answer sheets. Each team gets:

- A **front page** with an overview of all rounds, question counts, and points per round.
- One **answer page per round** with questions and write-in space (or multiple-choice options).

Tap **Print** to send to your printer. Cut the pages into packets — one per team.

### 4. Score the Quiz

The **Scoring** screen shows:

- **Round tabs** across the top — tap to switch between rounds (S1–S7, Varia, Photo).
- A **scoring table** with teams as rows and questions as columns.
- For each cell: tap **✓** (correct) or **✗** (wrong). Tap again to undo.
- The **last column** shows each team's total for that round.

Additional controls in the top bar:

| Button | What it does |
|--------|-------------|
| **Show/Hide Answers** | Toggles a row showing the correct answer for each question |
| **Setup** | Go back to edit teams |
| **Leaderboard** | Open the leaderboard reveal |
| **Close / Reopen** | Lock or unlock the session (prevents further player answers) |

Player-submitted answers appear as small text below the score buttons, so the host can compare answers before scoring.

### 5. Reveal the Leaderboard

The **Leaderboard** screen is designed for a projector:

- Tap **Reveal #N** to show teams one at a time, from last place to first — a sound effect plays with each reveal for dramatic effect.
- Or tap **Show All** to reveal everyone at once.
- The #1 team gets a winner fanfare.
- Top 3 teams get gold, silver, and bronze medals with glowing cards.
- Each card shows a progress bar, total score, and a per-round breakdown.
- Teams are shown by their **custom team name** (chosen by players when they joined).

Tap **Back to Scoring** to return.

### 6. Resume a Session

If you close the browser, just return to the lobby and enter your session code under **Join Existing Session**. The app picks up exactly where you left off.

You can also use **View All Sessions** to see every session with its status, then tap **Join** on any row.

## For Players

### 1. Join a Session

On the lobby, enter the session code under **Join as a Player** and tap **Find**. Then tap your **team name** from the list and tap **Join as Player**.

### 2. Choose a Team Name

When you first join, you'll be asked to **choose a custom team name** (e.g. "Birdie Brigade" or "The Bogey Men"). This is mandatory — you can't see questions until your team picks a name. If another player on your team already set a name, the prompt disappears automatically.

You can change the team name later by tapping the **team name badge** (with pencil icon) in the header.

### 3. Answer Questions

The **Player** screen shows:

- **Round tabs** at the top — when the host opens a new round, you're automatically navigated to it.
- **Question cards** with an input for each question.

Depending on the question type:

| Type | How to answer |
|------|--------------|
| **Open** | Type your answer in the text field |
| **Multiple choice** | Tap one of the four options |
| **Image** | Look at the projected screen, then type your answer |
| **Pick from list** | Tap the correct name from the pill list |

Tap **Submit** to send your answer. You'll see a gold checkmark once it's saved. You can change your answer and tap **Update** at any time (as long as the round is open).

### 4. Answer Reveal

When the host **closes a round**, you'll see a gold banner: *"Answers will be revealed shortly."* Correct answers are **not shown yet** — this gives the quiz master time to present answers one by one on the projector.

Once the host **opens the next round**, you're automatically navigated there. You can tap back to the previous round tab to see the correct answers (green banner: *"Review correct answers below"*).

When the session is fully closed, all answers for all rounds are revealed.

### 5. Session Closed

When the host closes the session, a red banner appears and all inputs are locked. Answers can no longer be changed.

Tap **Leave** in the header to exit and return to the lobby.

## Managing Quiz Content

From the lobby, tap **Manage Quiz** to open the content editor. Here you can:

- **Reorder rounds** with the arrow buttons.
- **Edit a round**: change the name, subtitle, type (Series / Varia / Photo), and max points.
- **Edit questions**: set the label, question text, correct answer, type, and options.
- **Add or delete** rounds and questions.
- Tap **Save Round** to persist your changes.

Changes to quiz content apply to all future sessions.

## Tips

- **Projector setup**: Open the app on a laptop connected to the projector. Use the Scoring view during rounds and switch to the Leaderboard for the reveal.
- **Player devices**: Players only need their phone — the interface is mobile-optimised.
- **Mid-quiz break**: Close the session to lock answers, reopen when you resume.
- **Answer sheets**: Print physical answer sheets from the Setup screen for rounds that aren't played via the app (e.g. Varia, Photo).
- **Sound effects**: The leaderboard plays reveal sounds and a winner fanfare — make sure volume is up on the projector device.
- **Multiple hosts**: Any device that joins with the session code as host can score — but avoid two hosts scoring at the same time.
